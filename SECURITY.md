# Security Policy

AgentOS is at an early foundation stage and does not yet provide a production execution service.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues. Use GitHub's private vulnerability reporting for the repository when available. Until a public repository is established, contact the project maintainer through a private channel and include only the information needed to reproduce the issue. Do not send real credentials or unrelated personal data.

We will acknowledge reports as soon as practical, assess impact, and coordinate a fix and disclosure timeline with the reporter. No response-time guarantee is established yet.
