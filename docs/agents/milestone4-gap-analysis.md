Migration version 2 in SQLite and PostgreSQL adds approval principal, policy version, expiry, consumption and revocation fields plus a principal/state index. Rollback is reversible only while the new audit fields remain empty; the runner rejects rollback that would discard populated approval state. Event payloads are JSON, so adding consumed/revoked event variants needs no SQL migration. Trusted authentication, execution wiring and runtime verification remain outstanding.

## Delivery boundary

M4.1 Docker command/runtime contracts and Git worktree code have automated tests, but this machine has neither Docker nor OpenCode. Real sandbox enforcement and live execution stay `BLOCKED`. M4.2 coordinator code and SQLite tests are implemented. Startup recovery now includes guarded cleanup logic, but its Docker commands are not daemon-verified and no distributed leases exist. Result persistence is limited to summary and hashes, and actor-bound approvals remain. No phase beyond Milestone 4 is authorized.
