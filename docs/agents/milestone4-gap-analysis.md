Existing database migration version is 1 for both SQLite and PostgreSQL. The existing run `workspace_id`, status timestamps, immutable manifest, ordered event log and approval table are reusable. They are insufficient for session/runtime ownership, idempotency, interrupted recovery, approval expiry/revocation, and principal/capability binding. Such additions require a new versioned migration in both dialects; no migration is justified until the coordinator and approval data contract are implemented together.

## Delivery boundary

M4.1's Docker invocation/runtime contract and Git worktree implementation are unit-tested, but this machine has neither Docker nor OpenCode. Real sandbox enforcement and OpenCode execution stay `BLOCKED` until the container-backed adversarial and live tests run. M4.2 and M4.4–M4.7 remain in progress; M4.3 has partial implementation without result persistence or adversarial platform coverage. No phase beyond Milestone 4 is authorized.
