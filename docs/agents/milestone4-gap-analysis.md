Migration version 2 in SQLite and PostgreSQL adds approval principal, policy version, expiry, consumption and revocation fields plus a principal/state index. Migration version 3 adds `run_artifacts` with a composite run/project foreign key, unique logical-name key, integrity/status checks and lookup indexes. Migration rollback is guarded against deleting approval audit data or artifact metadata. Event payloads are JSON; artifact events contain only identifiers, digests, sizes and collection statuses. Trusted authentication, execution wiring and runtime verification remain outstanding.

## Delivery boundary

M4.1 Docker command/runtime contracts and Git worktree code have automated tests, but this machine has neither Docker nor OpenCode. Real sandbox enforcement and live execution stay `BLOCKED`. M4.2 coordinator code and SQLite tests are implemented. M4.3 durable diff/manifest/result artifacts and metadata are implemented; current OpenCode stdout, stderr and structured tests are explicitly unavailable. Startup recovery includes guarded cleanup logic, but its Docker commands are not daemon-verified and no distributed leases exist. Trusted authentication and execution-time grant enforcement remain blockers; a separate human-approval workflow is not implemented. No phase beyond Milestone 4 is authorized.
