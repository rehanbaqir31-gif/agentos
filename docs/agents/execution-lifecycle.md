# Execution lifecycle

The core run lifecycle is the source of truth: `created → validating → preparing_workspace → queued → running`, with terminal `succeeded`, `failed`, or `cancelled` outcomes and `waiting_for_approval` for external decisions. Persist status transitions and normalized events using `@agentos/core` contracts and database repositories. Session identity is associated with the run; results come from the run workspace's Git state. Cancellation must be safe to repeat. A process restart should reconcile active runs against persisted adapter session state before resuming or marking them failed.

`GitWorkspaceManager` now creates a detached per-run worktree at a full commit SHA, preserves source edits, collects changed paths/hash/diff and removes only its owned worktree. `DockerIsolatedRuntime` requires an image pinned by digest, mounts only that worktree read-only, disables networking, binds the OpenCode server to host loopback, drops Linux capabilities, applies fixed CPU/memory/process limits, and kills/cleans up on cancellation/disposal. It deliberately refuses `supervised` and `autonomous` because trusted AgentOS approvals are not implemented.

`ExecutionCoordinator` now creates a run, validates project/task/agent/provider selection, advances lifecycle statuses, allocates and attaches a session, writes a versioned manifest, ingests normalized SDK events after a subscription-ready handshake, collects a result snapshot, persists its file/diff hashes, and records terminal completion/failure/cancellation. Source event IDs and permission records are deduplicated. Read-only permission requests are durably rejected before the adapter response; broader approvals fail closed. Coordinator tests run against SQLite.

`recoverInterruptedRuns()` is an explicit single-worker startup operation: it finds persisted nonterminal runs, marks them failed with a `PROCESS_INTERRUPTED` event, and never replays a prompt. Call it before accepting new work. It is idempotent and tested by closing and reopening SQLite. It does not yet inspect or clean up orphaned Docker containers/worktrees, acquire distributed leases, or reattach sessions. Persisted raw diffs/artifact bundles, stdout/stderr and test capture are also outstanding. Real Docker isolation is unverified on this machine.
