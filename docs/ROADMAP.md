Milestones 2 and 3 are verified. Milestone 4 includes the OpenCode adapter, Docker runtime, detached Git worktree, durable coordinator, approval infrastructure, durable result artifacts, worker leases and (M4.7) a local trusted authentication/API boundary. M4.5's per-run network and restricted container profile passed Docker daemon CI with a protocol shim, not OpenCode. M4.6A validates the SDK 1.19.5 prompt response's assistant/session identity, completion timestamp and typed errors; outcomes distinguish success, failure, cancellation, timeout and incomplete execution. Runtime CLI calls now invoke the candidate image's `opencode` entrypoint only once. The upstream image's OCI index/platform/config metadata was inspected via registry APIs; the source release commit is unsigned, and the image has not been pulled or run. A host-side credential broker is the preferred provider design but remains design-only and requires security review. Real-image startup/task and runtime failure/cancellation checks remain blocked: this Windows environment has no Docker, no provider is configured, and no reviewed broker exists. CI run [42381765534](https://github.com/rehanbaqir31-gif/agentos/actions/runs/42381765534) passed the previous M4.6 commit's quality, PostgreSQL 16 and protocol-shim Docker jobs. OpenCode stdout/stderr and structured test results remain unavailable. M4.7's local API authenticates with a one-time bootstrap password and opaque revocable sessions, checks project/run scope, and revalidates policy/session/run lease immediately before adapter execution. This is not a multi-user remote authentication system. Permission grants remain policy self-grants, not independent human approvals, and write actions are denied. Only `read_only` remains permitted. Docker is defense in depth and does not eliminate host kernel/daemon, host-gateway or image-supply-chain risk. Phase 5 and dashboard work are not started.

## First MVP milestone

Complete one real agent task in an isolated test repository and verify streamed, persisted events, permission checks, cancellation, and Git diff collection. Do not start dashboard breadth or additional adapters before this vertical slice works.
