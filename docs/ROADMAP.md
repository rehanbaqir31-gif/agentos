Milestones 2 and 3 are verified. Milestone 4 includes the OpenCode adapter, Docker runtime implementation, detached Git worktree snapshot layer, durable run coordinator, approval domain/persistence/policy infrastructure, M4.3 bounded filesystem result artifacts, and M4.4 durable worker leases with generation fencing and non-replaying recovery. SQLite and local PGlite checks are available; PostgreSQL 16 CI is the required real-server concurrency verification. Artifact IDs converge across retries and object deletion is deferred through the cleanup grace period. OpenCode stdout, stderr, and structured test results remain unavailable because the adapter/runtime does not expose them. The approval service has no trusted principal source and is not connected to execution; only `read_only` remains permitted. Docker cleanup is command-double tested but not verified with a daemon. Actual sandbox isolation and live OpenCode execution remain unverified because Docker and OpenCode are unavailable. Do not begin Phase 5 or dashboard work until the full vertical slice, PostgreSQL concurrency suite and security audit pass.

## First MVP milestone

Complete one real agent task in an isolated test repository and verify streamed, persisted events, permission checks, cancellation, and Git diff collection. Do not start dashboard breadth or additional adapters before this vertical slice works.
