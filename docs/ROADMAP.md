Milestones 2 and 3 are verified. Milestone 4 now includes the OpenCode adapter, Docker runtime implementation, detached Git worktree snapshot layer, and a durable coordinator for run/session/manifest/event/result-hash persistence. Explicit startup recovery marks in-flight runs failed without replay, but does not yet clean orphan runtime resources or support multiple workers. Coordinator, Docker command construction and host Git behavior have automated tests; actual sandbox isolation and live OpenCode execution remain unverified because Docker and OpenCode are unavailable. Trusted actor-bound approvals, durable artifact capture and real task evidence remain. Do not begin Phase 5 or dashboard work until the full vertical slice and security audit pass.

## First MVP milestone

Complete one real agent task in an isolated test repository and verify streamed, persisted events, permission checks, cancellation, and Git diff collection. Do not start dashboard breadth or additional adapters before this vertical slice works.
