# Contributing

The project is in its foundation stage. Please discuss substantial architectural changes before opening a large implementation. Do not include credentials or real secrets in code, fixtures, logs, or issue reports.

## Local checks

Use Node.js 22+ and pnpm 11.25.0. Run `pnpm install`, then `pnpm check-types`, `pnpm lint`, `pnpm test`, `pnpm build`, and `pnpm format:check` before submitting changes. Add focused tests and update the relevant architecture or implementation-status documents with behavior and limitations.

## Security reports

Do not report vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md).
